# Озвучка — фразы для записи

Финальный голос — записи владельца. Пока их нет, в `public/voice/` лежат **временные файлы голосом Milena** из macOS (`npm run voice:placeholder`, задача 6). Запись владельца подменяет файл фраза за фразой, без правок в коде.

> ⚠️ Репозиторий публичный (иначе бесплатный GitHub Pages не работает), поэтому записи будут доступны всем по ссылке. В фразах нет имени ребёнка и ничего личного — так и оставляем.

## Как записать
1. iPhone, приложение «Диктофон», тихая комната, телефон в 20–30 см ото рта.
2. **Одна фраза = один файл.** Перед фразой и после — секунда тишины, обрезать не нужно.
3. Говорить живо, с улыбкой, чуть медленнее обычного. Можно записать 2–3 дубля и выбрать лучший.
4. Назвать файл по `id` из таблицы (например, `praise-1`), сложить в одну папку и передать её Claude Code: `npm run voice:import <папка>` (появится в задаче «audio»). Скрипт сам обрежет тишину, выровняет громкость и положит файлы в `public/voice/<id>.m4a`.
