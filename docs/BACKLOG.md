## Правила механик (20.11, по наблюдениям владельца и скринам оригиналов)

**Color Jam**
- Блоки — детали «Лего»: 1×1, 1×2, дальше L и T.
- Выходы-ворота по краю поля, у каждого свой цвет и ширина. Блок уходит, если цвет совпадает и блок помещается по ширине.
- Ход: блок перетаскивается по пустым клеткам по любому пути (как в Color Block Jam), а не только по прямой. Блоки-стрелки (мир 3) — только по своей оси.

**Муравьи**
- Сверху картинка из пикселей. Под ней пул из **5 слотов**. Между картинкой и пулом — дырка-муравейник. Внизу — колонки стопок цветных блоков, на каждом блоке число муравьёв.
- Тап по верхнему блоку колонки → блок уходит в свободный слот. Слотов нет — тап не срабатывает.
- Муравьи блока по одному бегут по краю картинки, **каждый съедает 1 доступный пиксель своего цвета** (на внешнем крае оставшейся картинки) и уносит его в дырку.
- Блок исчезает из слота, когда все его муравьи забрали по пикселю. Слот освобождается.
- Нет доступных пикселей своего цвета → муравьи ждут, слот занят. 5 занятых слотов, и никто не может есть → тупик (у нас — пульс Undo).
- Сумма муравьёв цвета = число пикселей этого цвета в картинке. Сложность — порядок блоков в колонках, число колонок и цветов, позже скрытые блоки «?» (цвет виден, когда блок стал верхним).
- В оригинале картинки крупные (≈40×30). У нас стартуем с 16×16 и растим размер вместе со сложностью.
